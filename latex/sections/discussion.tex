\section{Discussion}
The clustering result is not surprising in isolation (clustered data need clustered inference), but its size is: reporting one pooled interval from several runs per task is common and, with ten runs per task, wrong by about twenty-five coverage points when tasks differ. The public re-analysis shows the consequence for leaderboards: with 500 instances and one run each, most pairs are separable but neighbouring entries almost never are, and small gaps are not resolved even with 500 tasks in simulation. None of this says leaderboards are useless: large gaps are reliably detected, and the top of the SWE-bench ranking is clearly above the bottom. It says that nearby rank positions should not be read as an ordering, and that ``not distinguishable'' is a statement about the evidence, not about the agents.

\paragraph{Recommendations.} (i) Treat tasks as the sampling unit and report task-bootstrap or hierarchical intervals when $R>1$ or $T\ge50$ (in our simulation grid the task bootstrap is mildly optimistic, and the hierarchical interval relies on a beta model for task difficulty, Section~\ref{sec:intervals}); for very small single-run evaluations use an exact binomial interval. (ii) Compare agents on the same tasks with paired task-level tests and correct for multiplicity (Holm by default). (iii) Plan with the variance decomposition: prefer more tasks over more repeats when the agent-by-task interaction is non-negligible, prefer repeats when the task pool is capped or tasks are costly, and treat pilot-based task counts as orders of magnitude. (iv) Report pass$^k$ with pass@$k$. (v) If monitoring an evaluation as it runs, use a confidence sequence, not repeated fixed-sample tests, and pre-declare an equivalence margin if equivalence is the goal. (vi) Publish per-task, per-run outcomes and the number of attempts per submission, so that others can do this.

\paragraph{Parts of the hypothesis that were weakened or not supported.} \REALREFUTED{} Three further corrections to the first version of this study: the claim that \emph{no} adjacent SWE-bench position is distinguishable holds only for the full set of entries (Table~\ref{tab:swerobust}); ``more tasks beat more repeats'' depends on the interaction and on whether the task pool is capped; and the sign-flip test is exact only for symmetric differences, although it did not over-reject for skewed ones.
