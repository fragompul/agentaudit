# Reproducing

Every number in the README and paper is generated by a script from files in `results/`.

```bash
make install
make test
make reproduce      # simulations, re-analyses, figures (no model needed)
```

Real-model runs need [Ollama](https://ollama.com) and about 15 GB of disk. They are resumable and recorded in a record/replay cache:

```bash
OLLAMA_NUM_PARALLEL=4 ollama serve &
python scripts/run_real.py --models qwen2.5-3b llama3.2-3b --runs 10 --workers 4
```

Seeds are fixed everywhere; `configs/models.json` lists the exact model tags. Raw trajectories are published as release assets, not in git.
