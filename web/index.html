Statistics for agent evaluation

How much of a leaderboard is signal?

Agent leaderboards report one number per system, from one run. AgentAudit is the toolkit, the benchmark and the empirical study that tell you how much of that number you can trust, including the parts of our own hypothesis the data did not support.

The toolkit

One library. Eight ways to doubt a number.

metrics

Unbiased reliability

pass@k and pass^k estimators, bias-corrected per task.

intervals

Honest uncertainty

Wilson, Clopper-Pearson, beta-binomial, task, run and two-stage bootstrap, BCa.

variance

Crossed decomposition

Agent × task × run ANOVA with a generalizability coefficient.

comparison

Paired, exact tests

Sign-flip permutation, cluster bootstrap, McNemar, Holm and BH.

ranking

Rank distributions

P(top-k), pairwise P(i > j), split-half Kendall τ.

planning

Power and cost

Minimum detectable effect, cost-optimal runs per task, tasks vs repeats.

sequential

Stop early, safely

Anytime-valid betting confidence sequences with equivalence margins.

failures

Where agents break

Deterministic taxonomy and failing-step localisation. Tokens, never money.

AgentAudit-Bench

A benchmark that audits itself

Six simulated worlds, tasks generated from a seed with controllable horizon, distractors and tool failure rate. Success is decided by the final state of the world, never by what the agent says.

Every task is audited: an oracle solves it, a do-nothing agent does not, and generation is deterministic.

Honesty

What this does not show

  • The real-model study uses 1B to 7B quantised local models on one laptop. Absolute scores do not transfer to frontier agents; generality rests on the simulations and the public re-analysis.
  • The environments are simulated and cleaner than real software tasks.
  • Tasks are treated as i.i.d. draws from the generator's population; intervals refer to that population.
  • The SWE-bench re-analysis assumes every public submission was evaluated on all 500 Verified instances.
